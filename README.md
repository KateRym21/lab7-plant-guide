# Гід по кімнатних рослинах

Навчальна веб-сторінка (лабораторна робота, варіант 26): правила поливу, освітлення та догляду за популярними кімнатними рослинами.

## Використані технології
- HTML5 (семантичні теги: header, nav, main, section, article, footer)
- CSS3 (змінні, селектори, псевдокласи, transition)
- Flexbox (шапка, блок загальних правил, теги)
- CSS Grid (сітка карток рослин)
- Адаптивний дизайн (media queries: 900px і 600px)

## Структура
- `index.html` — розмітка сторінки
- `style.css` — стилі
- `script.js` — інтерактивність (JavaScript)

## Можливості JavaScript
- анімація листочків, що падають (динамічне створення елементів)
- клік по рослині поливає її: краплі, лічильник, підказка про перелив
- «Мій садок»: додавання й видалення рослин, вологість ґрунту, що зменшується з часом
- пошук за назвою та фільтр за складністю догляду
- перемикач світлої/темної теми (збереження в localStorage)
- поява елементів при прокрутці, кнопка «Нагору»
- повідомлення для налагодження в консолі браузера (F12)
